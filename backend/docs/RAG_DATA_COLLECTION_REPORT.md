## 📊 项目概览

UniPulse Asia是一个面向亚太地区大学生的社交与职业发展平台，集成了强大的RAG（检索增强生成）系统，为学生提供9大AI辅助功能。

### 🎯 项目目标

通过3轮数据采集（Round 1-3），构建涵盖学术、职业、创业三大领域的综合知识库，支持智能问答和内容生成。

## 🛠️ 技术实现

### 数据采集工具

所有爬虫脚本位于：`backend/scripts/crawlers/`

| 爬虫脚本 | 数据类型 | 状态 |
|---------|----------|------|
| `academic_crawler.py` | 学术资源 | ✅ |
| `interview_crawler.py` | 面试题库 | ✅ |
| `news_crawler.py` | 创业新闻 | ✅ |
| `resume_crawler.py` | 简历模板 | ✅ |
| `bp_crawler.py` | BP模板 | ✅ |
| `company_crawler.py` | 公司信息 | ✅ |
| `market_crawler.py` | 市场报告 | ✅ |
| `salary_crawler.py` | 薪资数据 | ✅ |

### RAG系统架构

**向量数据库：** PostgreSQL + pgvector  
**Embedding模型：** nomic-embed-text (Ollama)  
**文本分块：** RecursiveCharacterTextSplitter (chunk_size=500, overlap=100)  
**检索方式：** 余弦相似度向量检索

### 数据导入流程

每个数据源遵循统一的5步流程：

1. **爬虫采集** - 生成测试数据（~5条）
2. **数据验证** - 验证数据质量和完整性
3. **RAG测试** - 测试检索效果
4. **扩大规模** - 生成完整数据集
5. **正式导入** - 导入到RAG系统

## 📝 使用说明

### 数据更新

如需更新某个数据源：

```bash
# 1. 运行爬虫
python backend/scripts/crawlers/{数据源}_crawler.py

# 2. 验证数据
python backend/scripts/validate_{数据源}.py

# 3. 导入数据
python backend/scripts/import_{数据源}_full.py
```

### RAG查询

```python
from apps.ai.services.rag_engine import RAGEngine

rag = RAGEngine()
docs = rag.retrieve("Software Engineer在马来西亚的薪资是多少？", top_k=3)
for doc in docs:
    print(doc.page_content)
    print(f"相似度：{doc.metadata['similarity']}")
```
