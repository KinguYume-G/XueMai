### 2. 数据格式标准化
```json
{
  "question": "问题内容",
  "category": "算法/系统设计/行为",
  "difficulty": "简单/中等/困难",
  "answer": "参考答案（可选）",
  "source": "数据来源",
  "license": "MIT",
  "attribution": "原作者信息",
  "source_url": "原始URL"
}
```

每个导入的问题都会包含：
- 原始来源
- 许可证类型
- 作者归属
