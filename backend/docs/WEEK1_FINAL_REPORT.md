## 🔧 技术架构

### 爬虫架构
```
BaseCrawler (基类)
├── AcademicCrawler (学术资源)
├── NewsCrawler (RSS新闻)
└── InterviewCrawler (面试题生成)
```

### 数据处理流程
```
1. 数据爬取 → 2. 数据验证 → 3. RAG导入 → 4. 检索测试
   ↓              ↓              ↓              ↓
  JSON文件      质量评分      分块+向量化    相似度检测
```

### RAG系统
- **向量模型：** nomic-embed-text (768维)
- **向量数据库：** PostgreSQL + pgvector
- **分块策略：** RecursiveCharacterTextSplitter (chunk_size=500)
- **检索方式：** 向量相似度搜索（top_k=3）
